# Lab 8: BMI Calculator - Building Flutter UI for Intermediates

React Native and TypeScript conversion of the Flutter BMI lab. Select gender, adjust height, weight, and age, then calculate BMI to see the category and interpretation. The result screen lets you return and recalculate.

## Run on Android

Requires Node.js 22.11 or newer and Android Studio/SDK setup.

```sh
cd source
npm install
npm run android
```

The demo video is stored separately on the developer's machine.
